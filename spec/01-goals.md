# 01. 项目目标与范围

## 1.1 核心目标

构建一个**多云原生 + 自托管混合**的 CI/CD 平台,具备以下核心能力:

1. **项目管理** — 统一管理代码仓库 (GitHub / GitLab / Gitee / 自建 Gitea) 与构建产物
2. **代码拉取与构建** — 触发式 / 定时 / Webhook 三种触发方式,支持 Docker / Buildpack / 原生命令多种构建
3. **多目标部署** — 自建 K8s、腾讯云 TKE、阿里云 ACK、物理机/VM 集群
4. **可视化流水线编排** — 拖拽式 DAG 编辑器 + YAML 双向转换
5. **企业级安全与审计** — RBAC、密钥保险箱、操作审计

## 1.2 用户角色

| 角色 | 典型用户 | 关注 |
|---|---|---|
| **平台管理员** | 运维负责人 | 集群接入、用户权限、资源配额 |
| **DevOps 工程师** | SRE / 平台开发 | 流水线模板、插件开发、监控 |
| **应用开发者** | 后端/前端工程师 | 项目接入、流水线编辑、查看构建日志 |
| **审批人** | 团队 leader | 生产部署审批、回滚授权 |
| **观察者** | PM / QA | 只读查看构建状态、版本历史 |

## 1.3 业务场景

1. **代码提交触发自动构建** — 开发推送代码 → Webhook → 自动跑测试 → 构建镜像 → 推送 Registry
2. **多环境流水线** — dev → staging → 审批 → prod (含 Canary / Blue-Green)
3. **跨云部署** — 主集群 TKE,灾备集群 ACK,定时同步
4. **物理机部署** — 数据库初始化脚本、Nginx 配置下发、systemd 服务管理
5. **定时任务** — 每日数据 ETL、每周安全扫描、月度账单生成

## 1.4 范围界定

### 在范围 (v1.0)
- 项目/流水线/执行记录全生命周期
- 多 Git 源 + 多云 K8s + 物理机
- 可视化编辑器 + YAML
- 插件市场基础能力
- RBAC + OIDC + 审计

### 不在范围 (后续版本)
- ❌ 内置代码托管 (依赖外部 Git 平台)
- ❌ 制品库 (对接 Harbor / Nexus / Artifactory)
- ❌ APM / 业务监控 (对接 Prometheus + Grafana)
- ❌ ChatOps (v2 评估)
- ❌ AI 辅助生成流水线 (v2 引入)

## 1.5 关键非功能需求

| 维度 | 指标 |
|---|---|
| 并发流水线 | 单实例 500+,集群模式 5000+ |
| 单流水线步骤数 | 500+ |
| 日志吞吐 | 单流水线 10MB/s 实时 |
| API P99 延迟 | < 200ms (非长任务) |
| 可用性 | 99.9% (单 region 多 AZ) |
| 数据保留 | 流水线记录 1 年 / 日志 90 天 (可配置) |
| 升级停机时间 | 0 (蓝绿/滚动) |
