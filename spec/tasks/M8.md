## E8.2 5 个开箱即用流水线模板 (2d)

### T8.2.1 模板系统 (0.5d) ✅
**步骤**:
- pipelines 表加 is_template 字段
- 模板克隆 API: POST /api/v1/pipelines/from-template
- 模板分类 + 标签
- 模板市场 UI

**验收**: 一键克隆模板到项目

**完成产物** (2026-06-11):
- 新表 `pipeline_templates` (010 迁移) — 解耦 pipelines 表, 避免污染:
  - slug 唯一 / name / description / category / tags(text[]) / spec(jsonb) / spec_raw / builtin / org_id(NULL=全局)
  - GIN 索引 tags + soft-delete (deleted_at)
- `api/internal/model/pipeline_template.go` 模型 + VisibleToOrg helper
- `api/internal/repository/pipeline_template.go` `PipelineTemplateStore`:
  - List 自动合并 全局 + 当前 org 私有, 支持 `category` / `tag`(text[] ANY) / `q` 过滤
  - GetBySlug 给克隆 API 用
- `api/internal/handler/pipeline_templates.go` 6 端点:
  - CRUD + POST /api/v1/pipelines/from-template (template_id 或 template_slug + project_id + name)
  - builtin 禁改禁删 (403), 跨 org 私有模板返 404 (不泄露存在性)
  - 克隆事务: INSERT pipelines + pipeline_versions(v=1) + 更新 current_version_id
  - spec 二次校验 (防止 seed 后 DSL 升级导致老模板失效)
- `api/pkg/builtintmpl/` 3 个内置模板 (node-docker-k8s / go-multi-platform / static-site-s3):
  - main.go 启动 seed (slug 冲突跳过, 不阻断启动)
  - 测试硬性保证 DSL 校验全过, 启动 fail-fast
- 9 个集成测试 in-tx 全过 (list 合并 / 创建 / 校验拒绝 / builtin 只读 / cross-org / 克隆 by slug / 跨 org project 403 / 模板不存在 / 缺参)
