## E0.2 数据库与迁移 (3d)

### T0.2.1 安装 golang-migrate (0.5d) ✅ 2026-06-09
**描述**: 数据库迁移工具
**步骤**:
- 引入 golang-migrate/migrate v4 + pgx v5 stdlib (registered driver)
- `api/internal/db/migrations/` 目录约定: `NNN_name.up.sql` / `NNN_name.down.sql` (golang-migrate v4 标准命名)
- `api/internal/db/migrate.go` 通过 //go:embed 把 SQL 全编进二进制
- `helios-api --migrate` 仅迁移退出;默认启动时自动跑 (--skip-migrate 可跳过)
- DSN 走 HELIOS_DB_DSN 环境变量

**验收**: `make migrate-up` 成功 / `migrate-down` 干净回滚
**完成产物**:
- api/internal/db/migrate.go (Migrate + Version 两 API,SQL embed)
- Makefile: migrate-up / migrate-down / migrate-create NAME=xxx / migrate-version 4 target,从 .env 自动 source DSN
- 实测: down -all → up → up 幂等 → version=6 / 16 业务表 + schema_migrations 全部就位
**踩坑**:
- `GOBIN=/usr/local/go/bin` 系统目录没写权限,改 `GOBIN=$(go env GOPATH)/bin` 装到用户目录
- //go:embed 路径必须相对当前 .go 文件,迁移目录从根目录 db/migrations 搬到 api/internal/db/migrations
- 编译期需手动 import `_ "github.com/golang-migrate/migrate/v4/database/postgres"` 才会注册 postgres driver
