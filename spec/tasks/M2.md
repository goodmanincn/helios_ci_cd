## E2.2 DAG 调度 (3d)

### T2.2.1 DAG 构建与拓扑排序 (1d)
**描述**: 把 stages 数组变成 DAG
**步骤**:
- `engine/dag.go`:
  - BuildDAG(pipeline) → DAG{Nodes, Edges}
  - DetectCycle()
  - TopologicalSort() → 分层结果 ([][]NodeID)
- 循环依赖错误带链路提示

**验收**: 5 stage DAG 排序正确 / 故意造环报错

---

### T2.2.2 矩阵展开 (1d)
**描述**: matrix 字段展开成多个并行 stage
**步骤**:
- `engine/matrix.go`: Expand(stage) → []Stage
- 笛卡尔积 + exclude 规则
- 每个展开 stage 带 matrix_index 和 matrix_values
- 上游 needs 自动连到所有展开实例

**验收**: matrix: {os: [linux,darwin], arch: [amd64,arm64]} 展开成 4 个 (含 exclude 测试)

---

### T2.2.3 调度器主循环 (1d)
**描述**: 按 DAG 顺序调度执行
**步骤**:
- `engine/scheduler.go`:
  - 维护 ready queue (依赖已满足)
  - 提交 stage 到 worker pool (Asynq)
  - 监听 stage 完成事件 → 推进下游
  - 失败传播 (除非有 if: always() / failure())
- 并发数可配置

**验收**: 5 stage 含并行 + 串行 + 矩阵,执行顺序符合 DAG
