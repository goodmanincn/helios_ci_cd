Helios CI/CD — 系统架构

多云原生 · 自托管混合 · 可视化流水线编排

核心数据流

  • • Webhook/Cron → Trigger → Pipeline Engine
  • • 生成 Run → Asynq 队列 → Runner Manager
  • • Runner 执行 → 实时日志 → WebSocket 推送
  • • 完成后日志归档 MinIO

多云适配

  • • ClusterProvider 接口统一
  • • 自建/TKE/ACK 各自实现
  • • 凭据存 Vault,STS 自动刷新
  • • 部署策略: Rolling/B-G/Canary/Recreate

安全模型

  • • JWT + OIDC + PAT 多种认证
  • • Casbin RBAC 细粒度授权
  • • AES-256-GCM + KMS 信封加密
  • • K8s Runner 命名空间 + NetworkPolicy 隔离
